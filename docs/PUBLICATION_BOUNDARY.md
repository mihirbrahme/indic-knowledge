# Publication Boundary

## Public

Only files inside:

`/content`

are eligible for Quartz publication.

## Private editorial workspace

The following directories must never be copied into `/content` automatically:

- `/research`
- `/data`
- `/scripts`
- `/templates`
- `/docs`

Material in `/research` may contain:
- unverified claims;
- rejected ideas;
- incomplete citations;
- AI-generated drafts;
- conflicting interpretations;
- speculative modern connections.

Nothing in `/research` is authoritative merely because it exists in the repository.

## Promotion rule

Research material may move into `/content` only after:
1. source verification;
2. claim review;
3. editorial approval.

Automations must preserve this boundary.
